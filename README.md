## Опис

Цей проєкт створює інфраструктуру в AWS за допомогою Terraform.  
Передбачено створення:

- S3-бакету з DynamoDB для збереження та блокування стейтів
- VPC з публічними і приватними підмережами
- ECR-репозиторію для зберігання Docker-образів

---

## Команди для роботи

```bash
terraform init -  Завантажує потрібні плагіни та налаштовує бекенд (S3 + DynamoDB).
terraform plan - Показує, які ресурси будуть створені або змінені.
terraform apply - Створює ресурси в AWS. Підтвердити треба буде написавши yes.
terraform destroy - Видаляє усю інфраструктуру, створену цим проєктом.
```

## Структура проєкту

s3-backend/
Створює S3-бакет з версіюванням для зберігання стейтів Terraform
Створює таблицю DynamoDB для блокування стейтів

vpc/
Створює VPC з 3 публічними і 3 приватними підмережами
Налаштовує Internet Gateway, NAT Gateway та маршрутні таблиці

ecr/
Створює ECR-репозиторій з увімкненим скануванням образів
Повертає URL репозиторію у вивід
